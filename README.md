# Civil War Quiz Project

An interactive web application featuring a Civil War quiz and a "What If" strategic decision game.

## Features

### 📝 Quiz
- Interactive quiz with 5 questions about the American Civil War
- One question at a time with navigation
- Grade Answer button to check your responses
- Immediate feedback on correct/incorrect answers

### 🤔 What If
- Strategic decision-making game
- Lead the North to victory through 5 critical stages
- Multiple paths with different outcomes
- Survive all stages to achieve Union Victory

## Files

- `index.html` - Main menu page
- `quiz.html` - Interactive Civil War quiz
- `whatif.html` - Strategic decision game

## How to Run

1. Start a local server in this directory:
   ```bash
   npx http-server -p 8000
   ```

2. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```

## Technologies

- JavaScript (vanilla)
