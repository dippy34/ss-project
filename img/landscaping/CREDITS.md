# Photo credits: landscaping.html

All photos are self-hosted WebP files in this folder, each exported at one or two widths (e.g. `-800.webp`, `-1440.webp`).
They are placeholders for a sample site. Swap them for the client's own photos, then update this file and the
"Photo credits" block in the page footer (or delete both if every remaining photo is the client's own).

The before/after pair (`leaves-before`, `leaves-after`) are two closely matched shots of the same yard by the same
photographer, not a pixel-aligned pair. Replace them with a real before/after from the client.
